# مختبر العلوم ثلاثي الأبعاد – الصف السادس (تطبيق ويب للهاتف)

تطبيق ويب تقدّمي (PWA) يُثبَّت على الهاتف كأنه تطبيق، ويعمل بعد أول فتح بدون إنترنت.

## محتويات المجلد
| الملف | وظيفته |
|---|---|
| `index.html` | التطبيق كاملًا (النماذج ثلاثية الأبعاد والمعلومات) |
| `manifest.webmanifest` | اسم التطبيق وأيقوناته وألوانه |
| `sw.js` | العمل دون اتصال بالإنترنت |
| `icons/` | أيقونات التطبيق |
| `.nojekyll` | يمنع GitHub من معالجة الملفات |

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub (مثلًا `science-lab`)، واجعله Public.
2. ارفع **كل** محتويات هذا المجلد إلى جذر المستودع (Add file ← Upload files)، بما فيها مجلد `icons` وملف `.nojekyll`.
3. من **Settings ← Pages**: اختر Source = `Deploy from a branch`، الفرع `main`، المجلد `/ (root)`، ثم Save.
4. بعد دقيقة تقريبًا يظهر الرابط: `https://اسم-المستخدم.github.io/science-lab/`

## التثبيت على الهاتف
- **أندرويد (Chrome):** افتح الرابط ← قائمة ⋮ ← «تثبيت التطبيق» / «Add to Home screen».
- **آيفون (Safari):** افتح الرابط ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

## ملاحظات
- يحمّل التطبيق مكتبة three.js من cdnjs والخط من Google Fonts في أول فتح فقط ثم يحفظهما للعمل دون اتصال. **يجب فتحه مرة واحدة على الأقل مع إنترنت.**
- لتحديث التطبيق بعد تعديل `index.html` غيّر `VERSION` في `sw.js` (مثلًا `v2`).
- يجب فتح التطبيق عبر رابط `https://` (GitHub Pages يوفره)؛ فتح `index.html` مباشرة من الجهاز يعمل لكن دون خاصية التثبيت.
