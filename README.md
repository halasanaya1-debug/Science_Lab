# مختبر العلوم ثلاثي الأبعاد – الصف السادس (الفصلان الأول والثاني)

تطبيق ويب (PWA) يُثبَّت على الهاتف. **التطبيق كله في ملف واحد: `index.html`**.

## الملفات
- `index.html` التطبيق كاملًا (الوحدات والدروس والمفردات والنماذج ثلاثية الأبعاد والألعاب)
- `sw.js` للعمل بدون إنترنت
- `manifest.webmanifest` + الأيقونات الأربع (png)

## النشر على GitHub Pages
1. في المستودع: Add file ← Upload files.
2. ارفع `index.html` و`sw.js` (وباقي الملفات إن لم تكن موجودة) واستبدل القديم بنفس الاسم، ثم Commit changes.
3. افتح: https://halasanaya1-debug.github.io/Science_Lab/

لا حاجة لـ term1.html ولا term2.html ولا data.js ولا games.js بعد الآن؛ يمكن حذفها إن كانت مرفوعة.
عند أي تعديل لاحق غيّر رقم `VERSION` في `sw.js` ليصل التحديث إلى الهواتف.
